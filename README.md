# ArunOps Observability GitHub Pages

A static GitHub Pages website for the ArunOps Observability YouTube series.

## Files
- `index.html` — website
- `style.css` — responsive styling
- `script.js` — dark/light theme toggle

## Deploy to GitHub Pages

1. Create a new GitHub repository, for example: `arunops-observability`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save and wait for GitHub Pages to publish the site.

Your page will normally be available at:
`https://YOUR-USERNAME.github.io/arunops-observability/`

## Customize
- Replace the YouTube URL in `index.html` with your ArunOps channel URL.
- Add video links to individual roadmap/modules.
- Change the copyright year or branding as needed.
