# ArunOps Observability Series

Multi-page GitHub Pages site for the ArunOps Observability YouTube series.

## Pages
- index.html — Introduction
- roadmap.html — 14-day roadmap
- day-01.html through day-14.html — class pages
- style.css — shared styling

## Publish
Upload all files to a GitHub repository, then open Settings → Pages → Deploy from branch → main → /(root) → Save.
